# Lucas Joly

Sou desenvolvedor com foco em soluções com IA generativa, automações e desenvolvimento backend.

Trabalho com **Python, Java e Spring Boot** na construção de APIs e serviços. Também desenvolvo aplicações com **Next.js** e exploro o uso de modelos de linguagem para resolver problemas práticos.

Criei o [OnboardIA](https://github.com/jzmlucas/onboarding-ai-opensource), um copiloto para onboarding com consulta a documentos; o [LexIA Local](https://github.com/jzmlucas/lexia-analise-local-de-documentos), uma ferramenta de análise documental com IA local; e o [AmbulancIA](https://github.com/jzmlucas/chamados-ambulancia-ia-generativa), uma simulação de central de chamados assistida por IA.

Também desenvolvo o **FolhaAgenda**, um SaaS para gestão de agendamentos.

Gosto de entender problemas de ponta a ponta e construir soluções que conectam aplicações, APIs e automações.
